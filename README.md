# Lamoom Plugin

Run somebody else's way of working, judged until it is good. [lamoom.com](https://lamoom.com)

This repo is a plugin marketplace for both Codex and Claude Code. Add it with the repo URL and no sparse path.

- Codex: Settings → Plugins → Add marketplace → `https://github.com/LamoomAI/lamoom-plugin`
- Claude Code: `/plugin marketplace add LamoomAI/lamoom-plugin`

The plugin lives in `plugins/codex` and `plugins/claude`; each bundles the `lamoom` skill and the MCP server at `https://console.lamoom.com/mcp`.
